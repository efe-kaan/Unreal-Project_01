# Unreal Project_01
My First Game Project Made with Unreal Engine

🏃‍♂️ 20 Seconds Challenge
Welcome to my game! Do you have what it takes to be fast? 😉

🎯 How to Play: You have exactly 20 seconds to finish the game! There is a countdown ticking... ⏳

If you finish before 20 seconds: You WIN! 🏆

If time runs out: You lose. 😢

🎮 Controls:

Move: W A S D

Jump: Space

⚠️ Warning: Be careful! Don't fall into the water 🌊 and watch out for the bombs 💣.

Good luck and have fun! 😉
